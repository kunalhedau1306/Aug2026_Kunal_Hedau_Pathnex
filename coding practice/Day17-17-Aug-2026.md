# 65. Taints and Tolerations

Taint:

```bash
kubectl taint nodes worker1 dedicated=database:NoSchedule
```

Toleration:

```yaml
tolerations:
  - key: dedicated
    operator: Equal
    value: database
    effect: NoSchedule
```

Critical concept:

```text
Toleration = allows
Affinity    = targets
```

A toleration alone does not force scheduling onto the tainted node.

# 76. Troubleshooting Methodology

Do not randomly change configurations.

Use:

```text
1. Understand the symptom
2. Identify the affected layer
3. Check status
4. Check logs/events
5. Check configuration
6. Check dependencies
7. Make one controlled change
8. Verify
9. Document the root cause
```

Example:

```text
Website unavailable
      ↓
Is container running?
      ↓
Is application listening?
      ↓
Is port mapping correct?
      ↓
Is Security Group allowing traffic?
      ↓
Is routing correct?
      ↓
Is DNS correct?
```

# 77. Production Mindset

```text
Restart everything
Delete resources
Change multiple settings
Run random commands
```

```text
Observe
 ↓
Collect evidence
 ↓
Identify root cause
 ↓
Make minimal change
 ↓
Verify
 ↓
Document
```

This is one of the most important DevOps habits.
