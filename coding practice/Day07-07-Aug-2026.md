# Day 07 -- AWS Fundamentals Notes

# 1. Cloud Computing

Cloud computing is the on-demand delivery of IT resources over the
Internet with pay-as-you-go pricing.

## Characteristics

-   On-demand self-service
-   Broad network access
-   Resource pooling
-   Rapid elasticity
-   Measured service

# 3. Cloud vs On-Premise vs Multi-cloud

## On-Premise

-   Own data center
-   High upfront cost
-   Full control
-   Responsible for hardware

## Cloud

-   Pay as you use
-   Fast provisioning
-   Elastic scaling
-   Global availability

## Multi-cloud

-   Uses multiple cloud providers
-   Avoids vendor lock-in
-   Higher operational complexity

# 4. AWS Global Infrastructure

-   Region: Geographic location (e.g. ap-south-1)
-   Availability Zone (AZ): One or more isolated data centers within a
    Region
-   Edge Location: Used by CloudFront for content delivery

# 5. EC2

Amazon Elastic Compute Cloud provides virtual servers.

Common instance purchasing: - On-Demand - Reserved - Savings Plans -
Spot - Dedicated Hosts

Lifecycle: Launch → Running → Stop → Start → Terminate

# 6. AMI

Amazon Machine Image is a template containing: - Operating System -
Software - Configuration - Optional application stack

One AMI can launch many EC2 instances.

# 7. IAM

IAM controls authentication and authorization.

## Users

Individual identities.

## Groups

Collection of users.

## Roles

Temporary permissions assumed by users or AWS services.

## Policies

JSON documents defining Allow/Deny permissions.

Best Practices: - Least privilege - MFA - Use Roles instead of long-term
access keys - Avoid root account

# 8. ARN

Amazon Resource Name uniquely identifies AWS resources.

Format:

arn:partition:service:region:account-id:resource

Example:

arn:aws:s3:::my-company-backups

Example IAM Role:

arn:aws:iam::123456789012:role/EC2AdminRole

# 9. S3

Simple Storage Service provides object storage.

Storage Classes: - Standard - Intelligent-Tiering - Standard-IA - One
Zone-IA - Glacier Instant Retrieval - Glacier Flexible Retrieval -
Glacier Deep Archive

Features: - Versioning - Lifecycle rules - Encryption - Replication -
Static website hosting

# 10. VPC

Virtual Private Cloud is your isolated network.

Components: - CIDR Block - Subnets (Public/Private) - Route Tables -
Internet Gateway - NAT Gateway - Security Groups - Network ACLs

# 11. IAM Policy Example

``` json
{
  "Version":"2012-10-17",
  "Statement":[
    {
      "Effect":"Allow",
      "Action":"s3:ListBucket",
      "Resource":"arn:aws:s3:::my-bucket"
    }
  ]
}
```
